## 📌 Sobre o Projeto
Este projeto realiza uma investigação profunda nos Microdados do ENEM 2020, o maior exame educacional do Brasil. O objetivo foi aplicar técnicas de **Ciência de Dados** para compreender como o contexto socioeconômico dos candidatos influencia diretamente o seu desempenho acadêmico.

## 🔍 O que foi analisado?
A análise focou em identificar padrões e disparidades através de:
- **Cruzamento de Variáveis:** Comparação entre as notas das provas (Matemática, Linguagens, Redação, etc.) e o perfil dos candidatos.
- **Fatores Socioeconômicos:** Impacto da renda familiar, escolaridade dos pais e acesso à tecnologia na nota final.
- **Estatística Descritiva:** Uso de métricas como média, mediana e distribuição para validar as hipóteses levantadas.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Tratamento de Dados:** `Pandas` e `NumPy` para limpeza e manipulação de grandes volumes de dados.
* **Visualização:** `Matplotlib` e `Seaborn` para a criação de gráficos de correlação, boxplots e histogramas.

## 📊 Principais Insights
- Identificação da forte correlação entre a escolaridade dos responsáveis e o desempenho do candidato.
- Visualização das desigualdades regionais e o impacto do acesso a recursos tecnológicos no ano da pandemia.
